# 紫金点云视觉设计

## 目标

把 `/experience` 的默认高亮点云调整为参考图中的沉浸式展览风格：纯黑背景、深紫到珊瑚金的粒子色带、细小圆点、低曝光和轻微发光。保留现有实时交互、SAM3 高亮和调优面板覆盖能力。

## 视觉方案

- 点云使用按深度着色，近处为暖金/珊瑚色，远处为暗紫色。
- 背景保持纯黑，整体曝光和明度降低，黑场面积明显保留。
- 点形改为圆点，尺寸略增但保持细碎，启用近大远小。
- 使用轻度发光叠加和极弱随机闪烁，避免形成高亮霓虹或强动画。
- 适度降低点密度，并用远近裁剪与深度雾弱化背景噪声。
- SAM3 命中区域继续使用现有高亮色与放大机制，不改变识别数据链路。

## 实现边界

- 仅修改 `_sam3hl_cfg` 的默认实时渲染参数和必要的调优面板初始值。
- 不修改 DA3 推理、点云几何、GLB 导出结构或识别逻辑。
- 不新增依赖，不改变 API 数据结构。
- 用户仍可通过 `/sam3tune` 实时覆盖所有视觉参数。

## 验收标准

- `/experience` 默认呈现黑底紫金点云，而非原始 RGB 点色。
- 点为圆形细粒，具有轻微空间层次和克制的发光感。
- 页面仍可拖拽视角，调优面板仍能保存并实时更新参数。
- Python 语法检查通过，页面与配置接口可正常访问。

## 验证方式

1. 对 `app.py` 执行 Python 语法编译检查。
2. 启动本地服务并访问 `/experience?demo=1` 与 `/sam3tune`。
3. 在浏览器中检查默认黑底、紫金色带、圆点和整体曝光。
4. 修改一个实时参数，确认画面能够响应且接口无错误。
